# Spec #1201 - Customize the look of the native Apache ECharts tooltip

## Context

This specification addresses issue `#1201`: https://github.com/Orange-OpenSource/ods-charts/issues/1201

ODS Charts supports two tooltip/popover modes:

- the native Apache ECharts tooltip, used when `externalizePopover()` is not called;
- an externalized tooltip/popover managed by ODS Charts, optionally rendered with Apache ECharts, Boosted 4, or Boosted 5.

The native Apache ECharts tooltip currently uses Apache ECharts default styling. The externalized tooltip/popover is already styled and managed by ODS Charts.

The purpose of this evolution is to add Orange Unified Design System styling to the native Apache ECharts tooltip options generated by ODS Charts, without changing the behavior or public API of `externalizePopover()`.

### Motivation and Context

Support a use of ODS Charts limited to the static generation of graph options through `setDataOptions()` and `getChartOptions()`, without requiring the dynamic behavior of `externalizePopover()`.

### Current State

In `src/theme/ODS.project.ts`, the tooltip configuration only contains axisPointer styling:

```typescript
tooltip: {
  axisPointer: {
    lineStyle: {
      color: 'var(--bs-border-color-subtle, #cccccc)',
      width: 1,
    },
    crossStyle: {
      color: 'var(--bs-border-color-subtle, #cccccc)',
      width: 1,
    },
  },
},
```

This configuration does not include styling for the tooltip itself (background, border, padding, text style, etc.), so when users do not call `externalizePopover()`, the tooltip uses Apache ECharts' default styling which does not match the Orange Design System.

### Available Popover Managers

- `ODSChartsPopoverManagers.NONE`: Default ECharts template (current default)
- `ODSChartsPopoverManagers.BOOSTED5`: Boosted 5 tooltip/popover
- `ODSChartsPopoverManagers.BOOSTED4`: Boosted 4 tooltip/popover

## Objectives

- Provide ODS-compliant styling for the native tooltip by default when users only use `setDataOptions()` and `getChartOptions()`
- Use CSS variables for colors to support light/dark mode automatically
- Preserve the existing public API and the behavior of `externalizePopover()`

## Out of Scope

- Changing the behavior or rendering of `externalizePopover()` - it will continue to work as before
- Modifying the public API of ODS Charts
- Changing the tooltip content or formatter - the native Apache ECharts content structure remains unchanged
- Adding new tooltip features - only default styling changes are in scope

## Backward Compatibility

This change is API-compatible, with an intentional visual change for users relying on the default Apache ECharts tooltip:

- Users who already use `externalizePopover()` will not be affected - their tooltips will continue to work as before
- The native tooltip will use ODS styling without any additional configuration
- Users can still override the default tooltip styling via `setDataOptions()` if needed
- Applications relying on the previous Apache ECharts default appearance may observe a visual change

## Functional Requirements

### 1) Default Tooltip Styling

Add default tooltip styling to `ODS_PROJECT` in `src/theme/ODS.project.ts` that:

- Uses CSS custom properties for all visual values, not only colors
- Implements the Orange Unified Design System visual style shown in the reference image
- Applies to the native Apache ECharts tooltip without requiring `externalizePopover()`

The target tooltip appearance is:

- white or theme-dependent background;
- thin black or theme-dependent border;
- square or nearly square corners;
- no visible shadow, or only a very subtle shadow;
- compact internal spacing;
- a bold category header;
- one row per series with a colored square marker, series name, and value aligned to the right;
- no fixed width; the tooltip width adapts to its content.

The tooltip content and formatter remain Apache ECharts native behavior. The reference image defines the expected visual presentation; it does not require a new formatter or a change to tooltip content generation.

All tooltip visual tokens must be exposed as CSS custom properties. This keeps the tooltip styling consistent with the existing ODS Charts theme mechanism and allows applications or themes to override the values without changing chart options.

### 2) Tooltip Properties to Configure

The following Apache ECharts tooltip properties should be customized:

| Property             | Default Value                                                                                      | Description                                       |
| -------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| `backgroundColor`    | `var(--ods-tooltip-background, var(--bs-body-bg, #ffffff))`                                        | Tooltip background                                |
| `borderColor`        | `var(--ods-tooltip-border-color, var(--bs-body-color, #000000))`                                   | Tooltip border                                    |
| `borderWidth`        | `1`                                                                                                | Border width; Apache ECharts requires a number    |
| `padding`            | `[8, 8]`                                                                                           | Internal padding; Apache ECharts requires numbers |
| `textStyle.color`    | `var(--ods-tooltip-text-color, var(--bs-body-color, #000000))`                                     | Text color                                        |
| `textStyle.fontSize` | `var(--ods-tooltip-font-size, 14px)`                                                               | Font size                                         |
| `extraCssText`       | `border-radius: var(--ods-tooltip-border-radius, 0); box-shadow: var(--ods-tooltip-shadow, none);` | Additional CSS                                    |

The following CSS custom properties must be defined by ODS Charts with the displayed fallback values:

| Variable                      | Fallback                        | Purpose               |
| ----------------------------- | ------------------------------- | --------------------- |
| `--ods-tooltip-background`    | `var(--bs-body-bg, #ffffff)`    | Tooltip background    |
| `--ods-tooltip-border-color`  | `var(--bs-body-color, #000000)` | Tooltip border color  |
| `--ods-tooltip-text-color`    | `var(--bs-body-color, #000000)` | Tooltip text color    |
| `--ods-tooltip-font-size`     | `14px`                          | Tooltip font size     |
| `--ods-tooltip-border-radius` | `0`                             | Tooltip corner radius |
| `--ods-tooltip-shadow`        | `none`                          | Tooltip shadow        |

The CSS custom properties must be declared in the ODS Charts CSS theme variables and referenced by `ODS_PROJECT` where Apache ECharts accepts CSS values. `extraCssText` may retain CSS property names and separators as structure, but all visual values inside it must come from CSS custom properties. Properties such as `borderWidth`, `padding`, and `textStyle.fontSize` must use the numeric types required by Apache ECharts.

### 3) Axis Pointer Styling (Enhancement)

Enhance existing axisPointer configuration:

| Property           | Default Value | Description  |
| ------------------ | ------------- | ------------ |
| `type`             | `'line'`      | Pointer type |
| `lineStyle.width`  | `1`           | Line width   |
| `crossStyle.width` | `1`           | Cross width  |

## Implementation Notes

### Location

The fix should be applied in:

- File: `src/theme/ODS.project.ts`
- Object: `ODS_PROJECT`
- Section: `tooltip`

### Change Description

Update the `tooltip` section in `ODS_PROJECT`:

```typescript
tooltip: {
  backgroundColor: 'var(--ods-tooltip-background, var(--bs-body-bg, #ffffff))',
  borderColor: 'var(--ods-tooltip-border-color, var(--bs-body-color, #000000))',
  borderWidth: 1,
  padding: [8, 8],
  textStyle: {
    color: 'var(--ods-tooltip-text-color, var(--bs-body-color, #000000))',
    fontSize: 'var(--ods-tooltip-font-size, 14px)',
  },
  extraCssText: 'border-radius: var(--ods-tooltip-border-radius, 0); box-shadow: var(--ods-tooltip-shadow, none);',
  axisPointer: {
    type: 'line',
    lineStyle: {
      color: 'var(--bs-border-color-subtle, #cccccc)',
      width: 1,
    },
    crossStyle: {
      color: 'var(--bs-border-color-subtle, #cccccc)',
      width: 1,
    },
  },
},
```

### Dependencies

- No external dependencies need to be added
- CSS variables are already used elsewhere in the codebase (e.g., `--bs-body-bg`, `--bs-body-color`, `--bs-border-color-subtle`)
- The `EChartsProject.tooltip` type must be extended to describe the new tooltip properties
- CSS variables are resolved when ODS Charts generates chart options. A later light/dark mode change requires `manageThemeObserver()` or another call to `getChartOptions()` to regenerate the options

## Testing Requirements

1. **Unit tests** should verify that:

- `getChartOptions().tooltip` contains the expected default styling
- CSS variables are used in the source theme and are resolved for the active mode when chart options are generated
- Default values are correctly set
- User-provided tooltip options from `setDataOptions()` override the corresponding defaults

2. **Integration tests** should verify that:
   - Creating a chart without calling `externalizePopover()` displays a tooltip with ODS styling

- The tooltip correctly adapts to light/dark mode after chart options are regenerated
- User can still override the default tooltip styling via `setDataOptions()`

3. **Regression tests** should ensure:
   - Existing behavior with `externalizePopover()` remains unchanged
   - No breaking changes to the public API
